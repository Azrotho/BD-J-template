# BD-J Template

Template Gradle pour faire des applications BD-J.

> [!NOTE]
> Ce projet est un projet expérimental et pour mon usage personnel. Si il vous intéresse vous pouvez l'utiliser et contribuer.

> [!IMPORTANT]
> La template a été en grande partie réalisé à l'aide de l'IA par manque de documentation sur le sujet. Si vous vous y connaissez et que vous trouvez que c'est pas bien n'hésitez pas à me le dire :D Si je prend plus de temps je ferais un refactoring pour que le code soit fait main. *(si vous avez une doc)*

Cette template contient toute les tâches gradle afin de compiler et packager ainsi que tester directement sur VLC en forçant Java 8 ainsi que les tâches pour récupérer les outils.

Il y a aussi un `AssetLoader` pour charger des assets à partir du `/assets` pour bypass la limite de 4Mo du jar.
